# Output Schema Documentation

This document describes every field in the output JSON produced by the PhD Shortlist Builder.

Output file location: `sample_output/<student_id>.json`

---

## Top-Level Fields

| Field | Type | Description |
|-------|------|-------------|
| `schema_version` | `string` | Schema version identifier. Currently `"1.0"`. |
| `student_id` | `string` | Matches the `student_id` field in the input profile. |
| `student_name` | `string` | Student's full name from the input profile. |
| `generated_at` | `string` | ISO 8601 UTC timestamp of when the pipeline ran. |
| `summary` | `object` | Aggregate statistics across all output candidates. |
| `student_signal` | `object` | Key signals extracted from the student profile (for traceability). |
| `candidates` | `array` | Ordered list of candidate professors, ranked by score descending. |

---

## `summary` Object

| Field | Type | Description |
|-------|------|-------------|
| `total_candidates` | `integer` | Total number of candidates in the output list. |
| `reach` | `integer` | Count of candidates assigned tier `"reach"` (QS rank 1–100). |
| `target` | `integer` | Count of candidates assigned tier `"target"` (QS rank 101–400). |
| `safety` | `integer` | Count of candidates assigned tier `"safety"` (QS rank 401+ or unranked). |
| `with_open_positions` | `integer` | Count of candidates who currently have an open funded PhD vacancy. |
| `with_email` | `integer` | Count of candidates for whom an email address was found. |

---

## `student_signal` Object

Included for transparency — shows what the parser extracted from the profile.

| Field | Type | Description |
|-------|------|-------------|
| `primary_keywords` | `array[string]` | Core research keywords extracted by Stage 1 (Gemini). |
| `thesis_topic` | `string` | Refined thesis topic statement. |
| `target_countries` | `array[string]` | Countries the student is targeting (hard constraint). |

---

## `candidates` Array — Per-Candidate Fields

Each element in the `candidates` array represents one verified, scored professor.

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `rank` | `integer` | No | Position in the ranked list (1 = highest score). |
| `name` | `string` | No | Professor's full name as found in the data source. |
| `institution` | `string` | No | Full name of the professor's institution. |
| `country` | `string` | No | Country of the institution. One of the student's target countries. |
| `email` | `string` | Yes | Email address if found via faculty page scrape. `null` if not found. |
| `homepage` | `string` | Yes | URL to the professor's faculty page or profile. `null` if not found. |
| `research_focus` | `string` | No | Short description of the professor's research area, derived from their paper titles. |
| `tier` | `string` | No | `"reach"`, `"target"`, or `"safety"` — based on QS ranking of institution. |
| `score` | `float` | No | Composite weighted score in range [0, 1]. Higher is better. |
| `score_breakdown` | `object` | No | Individual dimension scores (see below). |
| `qs_rank` | `integer` | Yes | QS World University Ranking of the institution. `null` if institution is not in the QS ranking table. |
| `open_position` | `boolean` | No | `true` if a currently open funded PhD vacancy was found for this professor. |
| `why_match` | `string` | No | 2–3 sentence personalised explanation of why this professor's research matches the student's profile. Generated by Gemini. |
| `evidence` | `array` | No | List of papers, grants, or position ads that support this candidate's inclusion. |
| `sources` | `array[string]` | No | Data sources where this candidate was found. Values: `"openalex"`, `"semantic_scholar"`, `"findaphd"`. |

---

## `score_breakdown` Object

Breakdown of the five scoring dimensions that compose the final `score`.

| Field | Type | Weight | Description |
|-------|------|--------|-------------|
| `research_overlap` | `float` | 40% | Cosine similarity between the student's embedding and the professor's paper abstracts. Range [0, 1]. |
| `recency` | `float` | 20% | Score based on how recent the professor's papers are. Full score if papers exist within last 3 years. Range [0, 1]. |
| `open_position` | `float` | 25% | 1.0 if an open funded PhD vacancy exists, 0.0 otherwise. |
| `citation` | `float` | 5% | Normalised h-index proxy. h=80 → 1.0, h=0 → 0.0. |
| `country_quality` | `float` | 10% | 1.0 if confirmed in target country, 0.5 if uncertain, 0.0 if not in target. |

**Composite score formula:**
```
score = 0.40 × research_overlap
      + 0.20 × recency
      + 0.25 × open_position
      + 0.05 × citation
      + 0.10 × country_quality
```

---

## `evidence` Array — Per-Evidence Fields

| Field | Type | Nullable | Description |
|-------|------|----------|-------------|
| `type` | `string` | No | Type of evidence. One of: `"paper"`, `"open_position"`. |
| `title` | `string` | No | Title of the paper or position ad. |
| `year` | `integer` | No | Publication year (papers) or listing year (positions). 0 if unknown. |
| `doi` | `string` | Yes | DOI for papers. `null` for position ads. |
| `url` | `string` | Yes | Direct URL. For papers: `https://doi.org/<doi>`. For positions: FindAPhD listing URL. |

---

## Tier Assignment Logic

| Tier | Criterion |
|------|-----------|
| `reach` | Institution QS rank ≤ 100 |
| `target` | Institution QS rank 101–400 |
| `safety` | Institution QS rank > 400, or institution not in QS ranking table |

For unranked institutions, the composite `score` is used as a secondary signal:
- score ≥ 0.75 → promoted to `target`
- score < 0.75 → remains `safety`
